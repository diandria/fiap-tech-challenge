# RFCs

Propostas de decisão técnica, com alternativas abertas à discussão. Uma RFC compara opções e
recomenda; o ADR derivado fixa a decisão e registra as consequências de conviver com ela.

## Regra de redação

Nenhum documento justifica uma decisão dizendo que o projeto pediu, que está no requisito ou que
alguém autorizou. Quem lê daqui a um ano não tem o enunciado em mãos, e "porque mandaram" não ensina
nada sobre o sistema. Cada documento se sustenta em mérito técnico.
