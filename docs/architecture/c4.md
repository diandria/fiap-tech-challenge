# Diagramas C4 — Car Repair Shop API

## Nível 1 — Contexto do Sistema

Quem interage com o sistema e quais sistemas externos estão envolvidos.

```mermaid
flowchart TD
    cliente["Cliente\n[Pessoa]\nProprietário do veículo;\naprova ou rejeita o orçamento"]
    atendente["Atendente\n[Pessoa]\nAbre OS e registra entrega"]
    mecanico["Mecânico\n[Pessoa]\nRealiza diagnóstico e execução"]
    admin["Admin\n[Pessoa]\nGerencia catálogo, usuários e estoque"]

    system["Car Repair Shop API\n[Sistema de Software]\nGerencia ordens de serviço, estoque,\nveículos e notificações ao cliente"]

    cliente   -->|"Aprova/rejeita orçamento\nvia REST API"| system
    atendente -->|"Abre OS, registra entrega\nvia REST API"| system
    mecanico  -->|"Diagnostica, adiciona itens/serviços,\nexecuta via REST API"| system
    admin     -->|"Gerencia catálogo e usuários\nvia REST API"| system
```

## Nível 2 — Contêineres

Contêineres de software em execução que compõem o sistema em tempo de execução.

```mermaid
flowchart TD
    user["Cliente\n[Browser / Postman]\nConsome a API via HTTP/REST"]

    subgraph k8s["Kubernetes — namespace: oficina"]
        api["Car Repair Shop API\n[Contêiner: Node.js 20 + Express]\nExpõe endpoints REST;\nimplementa Clean Architecture"]
        mongo["MongoDB 7\n[Contêiner: StatefulSet]\nPersiste todos os dados de domínio"]
        api -->|"Mongoose ODM\n:27017"| mongo
    end

    user -->|"HTTP REST\n:8080 (LoadBalancer)"| api
```

> O fluxo de deploy (CI/CD, Terraform, scripts de infraestrutura) está documentado em [docs/infrastructure/deploy-flow.md](../infrastructure/deploy-flow.md).

## Nível 3 — Componentes

Estrutura interna da API seguindo Clean Architecture.

```mermaid
flowchart TD
    subgraph layer4["Camada 4 — Frameworks & Drivers (src/frameworks/)"]
        express["Express App\n(app.ts / main.ts)"]
        routes["Rotas\n(authRoutes, serviceOrderRoutes, …)"]
        mongoose["Mongoose\n(conexão com banco)"]
        express --> routes
    end

    subgraph layer3["Camada 3 — Interface Adapters (src/adapters/)"]
        controllers["Controllers\n(AuthController, ServiceOrderController, …)"]
        gateways["Gateways / Repositories\n(MongoServiceOrderRepository, …)"]
        services["Services\n(ConsoleNotificationService)"]
        routes --> controllers
    end

    subgraph layer2["Camada 2 — Use Cases (src/use-cases/)"]
        usecases["Classes de Use Case\n(CreateServiceOrderUseCase,\nApproveBudgetUseCase, …)"]
        ports["Ports / Interfaces\n(IServiceOrderRepository,\nIStatusChangeNotifier, …)"]
        controllers --> usecases
        usecases -->|"depende de"| ports
    end

    subgraph layer1["Camada 1 — Entities (src/entities/)"]
        entities["Entidades de Domínio\n(ServiceOrder, Item, Customer, …)"]
        statemachine["Máquina de Estados\n(serviceOrderStateMachine)"]
        validators["Validadores"]
        usecases --> entities
    end

    gateways -->|"implementa"| ports
    services -->|"implementa"| ports
    gateways --> mongoose
```
